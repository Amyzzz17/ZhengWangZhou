# Dataset Metadata

## 1. Dataset Access

**Dataset Name:** China’s Solar PV Exports

**Data Source:** Ember, based on data from China’s General Administration of Customs (GACC).

**Dataset URL:** https://ember-energy.org/data/china-solar-exports-data/

**File Format:** CSV

**Description:**

This dataset provides monthly information on China’s exports of solar panels, cells, and wafers by destination country or region.

## 2. Expected Variables

| Variable | Description |
|---|---|
| Area | Export destination country, economy, or region |
| Date | Reporting month |
| Area type | Country/economy or regional aggregate |
| Region | Geographic region |
| Commodity code | Customs product code |
| Commodity type | Panels, cells, or wafers |
| Amount (items) | Number of exported items |
| Amount (kg) | Export weight in kilograms |
| Amount (USD) | Export value in US dollars |
| Commodity price | Monthly product reference price |
| Price unit | USD/W or USD/pc |
| Capacity (MW) | Estimated capacity of exported products |
| Cumulative capacity (MW) | Cumulative estimated exported capacity |

## 3. Spatial Coverage

**Geographic Coverage:** Global, by export destination country, economy, and region.

## 4. Temporal Coverage

**Time Period:** January 2017–August 2026

**Frequency:** Monthly

Separate data for cells and wafers begin in January 2022.

## 5. Permissions and Restrictions

**Data Accessibility:** Publicly available

**License:** Creative Commons Attribution 4.0 (CC BY 4.0)

**Usage Restrictions:** Attribution is required when sharing or adapting the data. Any changes should be identified.

**Citation Requirements:** Cite Ember’s *China’s Solar PV Exports*, include the dataset link and access date, and acknowledge GACC as the underlying trade-data source.

We will follow the data provider’s usage requirements and cite the original source in our analysis.
